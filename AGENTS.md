# Agent guidance

## Commands

- `npm run dev` — dev server (Turbopack). `npm run build` — production build. `npm run lint` — ESLint 9.
- No test script exists. No typecheck script either: run `npx tsc --noEmit` manually.
- Route types in `.next/types/**` / `.next/dev/types/**` are generated by `next dev`/`next build`; generate them before typechecking or you'll get "file not found" errors from `tsconfig.json` include paths.

## Stack / toolchain quirks

- Next.js **16.4.3**, App Router, React 19.3 (see warning block above — verify APIs against `node_modules/next/dist/docs/`).
- `next.config.ts` enables: **React Compiler** (`reactCompiler: true` — avoid manual `useMemo`/`useCallback` unless there's a measured need), **`cacheComponents`**, and **Turbopack** for dev/build.
- **Tailwind v4 is CSS-first**: there is no `tailwind.config` file. Theme tokens, CSS variables, and the dark variant live in `src/app/globals.css` (`@theme inline` block). Tailwind is wired through a Turbopack rule in `next.config.ts`, not PostCSS.

## shadcn/ui (base-nova variant — not classic shadcn)

- All UI primitives live in `src/components/ui/`, generated by the shadcn CLI (`components.json`, style `base-nova`).
- These wrap **Base UI** (`@base-ui/react`), **not Radix**. Import paths differ from what you likely remember, e.g. `Button` comes from `@base-ui/react/button`.
- `cn` is imported from the `cn` npm package (`src/lib/utils.ts` just re-exports it), not defined locally in `@/lib/utils`.
- Aliases (`components.json` + `tsconfig.json`): `@/*` → `src/*`; `@/components/ui`, `@/hooks`, `@/lib`.

## Layout

- `src/app/` holds the app (`layout.tsx` root layout with Comic Relief font, `page.tsx` is essentially empty). Everything app-specific goes here; `src/components/ui/` is generated kit code — don't restructure it.
